# Clothing rack starter

Turn your own shirts into an interactive 3D rack: each tee swivels on the rail, flips front to back, and switches
between three fabric colours. Live example: https://averlo-clothing-rack.vercel.app/

## Use it

Take two photos of each shirt (front and back), then paste this into your coding agent (Claude Code, Codex or Cursor):

```
Clone https://github.com/olafBobryk/averlo-clothing-rack-starter and follow its AGENTS.md to set up my 3D clothing rack. Use my two shirt photos, labeled front and back, for the first tee. Show me a preview where I can change the fabric color and flip the shirt to check both prints. Ask me before spending credits or publishing.
```

## What's here

- [AGENTS.md](AGENTS.md): the setup steps your agent follows.
- [rack-starter.json](rack-starter.json): one example shirt to copy (names, prints, colours).
- [rack-ui.css](rack-ui.css): the front/back toggle and colour tags.
- [shirts/](shirts/README.md): where your photos go.
